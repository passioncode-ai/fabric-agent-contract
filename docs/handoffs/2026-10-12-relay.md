# Handoff — the relay and the secret envelope (DEC-0047; `fabric-relay/0.1`, `fabric-secret-envelope/1`)

## Objective

Decide the relay protocol and the secret envelope for the relay server
([passioncode-ai/relay](https://github.com/passioncode-ai/relay), its RLY-02), Project Observatory's node and Fabric's
surfaces, after the operator's D6 (2026-10-12): the relay is its own open repository, self-hosting stays (V2-21).
